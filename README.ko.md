# 채팅 로비 사용 가이드

[English](README.md)

실리태번 시작 화면의 **'최근 채팅' 자리에 모든 캐릭터·그룹의 채팅 목록**을 보여 주는 확장입니다.
목록에서 바로 채팅에 들어가고, 이름을 바꾸거나 지울 수 있어요. 여러 개를 골라 한 번에 지울 수도 있습니다.
휴대폰에서 쓰기 편하게 만들었습니다.

---

## 1. 설치하기

1. 실리태번 위쪽의 **확장 프로그램**(퍼즐 모양 아이콘)을 누릅니다.
2. **Install Extension**을 누릅니다.
3. 이 저장소 주소를 붙여 넣고 **Install**을 누릅니다.

   ```text
   https://github.com/spaceship4415/st-chat-lobby
   ```

설치가 끝나면 시작 화면(채팅을 닫았을 때 나오는 화면)에 **전체 채팅** 목록이 보입니다.

---

## 2. 어디서 여나요?

- **시작 화면**: '최근 채팅' 대신 전체 채팅 목록이 보여요.
- **채팅 중에**: 입력창 왼쪽의 **마법봉 메뉴 → 전체 채팅**을 누르면 같은 목록이 창으로 열려요.

```text
전체 채팅 (50+)
[🔍 캐릭터·채팅·내용 검색    ] [☑] [⟳]
[전체 ▼]              [최근 순 ▼]
── 오늘 ──────────────────────
(사진) Seraphina              17:11  [✎]
       채팅 이름                      [🗑]
       마지막 메시지 한두 줄…
       메시지 52개 · 2.3KB
── 어제 ──────────────────────
…
        [50개 더 불러오기]
```

---

## 3. 목록 쓰기

- **채팅을 누르면** 바로 그 채팅에 들어갑니다.
- **검색**: 캐릭터·그룹 이름, 채팅 이름, **마지막 메시지**에서 찾아요(대화 중간의 메시지는 찾지 않아요). 여러 낱말을 띄어 쓰면 모두 들어 있는 채팅만 보여요.
  검색 결과는 **어디에서 찾았는지**에 따라 '캐릭터·그룹 이름 / 채팅 이름 / 마지막 메시지'로 나눠 보이고, 찾은 글자가 표시돼요.
  (실리태번은 채팅 이름에 만들 때의 캐릭터 이름을 넣어서, 캐릭터 이름을 바꾸거나 카드를 복사해도 채팅 이름은 옛 이름 그대로예요. 그래서 옛 이름으로 찾으면 '채팅 이름'에 나와요.)
  보기를 캐릭터나 그룹으로 좁혀서 결과가 숨으면 몇 개가 숨었는지 알려 주고 [전체 보기]로 바로 풀 수 있어요.
- **묶음 접기**: 날짜·캐릭터·찾은 곳 제목을 누르면 그 묶음이 접히고, 다시 누르면 펼쳐져요. 제목은 스크롤해도 위에 붙어 있어서 긴 묶음을 내려가다가도 바로 접을 수 있어요.
  접은 묶음의 채팅은 선택 모드의 **모두 선택**에 들어가지 않아요.
- **대화 내용까지 검색**: 검색하면 결과 맨 위에 카드가 생겨요. 누르면 모든 캐릭터·그룹의 채팅을 **대화 중간 메시지까지** 찾아서 **대화 내용** 묶음에 보여 주고, 찾은 메시지를 미리보기로 보여 줘요.
  채팅 파일을 끝까지 읽어서 오래 걸릴 수 있어요. 검색하는 동안 목록 맨 위 카드에 진행 막대와 찾은 개수가 보이고, **멈추기**로 언제든 멈출 수 있어요. 검색어를 바꾸면 결과는 사라지고 다시 누르면 돼요.
  여러 낱말이면 서로 다른 메시지에 흩어져 있어도 찾아요. 찾은 메시지 미리보기는 100개 채팅까지만 불러와요.
- **보기**: 전체 / 캐릭터 / 그룹.
- **정렬**: 최근 순 / 오래된 순 / 이름 순 / 메시지 많은 순 / 캐릭터별.
  최근 순·오래된 순은 **오늘, 어제, 이번 주, 이번 달, 2026년 9월 …** 제목으로 묶여요. 정렬은 마지막으로 고른 걸 기억해요. 보기(캐릭터·그룹)는 열 때마다 전체로 돌아가요.
- **⟳ 새로 고침**: 다른 곳에서 채팅을 만들거나 지웠을 때 목록을 다시 불러와요.
- 미리보기에서는 `*`, `**`, HTML 태그 같은 꾸밈 기호를 빼고 글자만 보여 줘요.

### 불러오는 개수

채팅이 많으면 한꺼번에 불러오는 데 오래 걸려서, **최근 채팅부터 정해진 개수만** 불러옵니다(기본 50개).

- 목록 맨 아래 **[50개 더 불러오기]**로 더 볼 수 있어요. 남은 채팅이 없으면 버튼이 사라져요.
- 제목의 **(50+)**는 '50개를 불러왔고 더 있다'는 뜻이에요. 끝까지 불러오면 정확한 개수가 보여요.
- 검색·보기·정렬은 **불러온 채팅 안에서** 적용돼요. 그때는 목록 위에 '불러온 최근 채팅 50개 안에서 보여 줍니다'라고 알려 줘요.
- 검색 중에 찾는 채팅이 없으면 **[모든 채팅에서 검색]**을 누르세요. 모든 채팅을 불러와서 다시 찾아요.

## 4. 이름 바꾸기 · 삭제

- 각 줄 오른쪽의 **✎**로 이름을 바꿔요. 같은 이름(대소문자만 다른 것 포함)이 있으면 바꾸지 않아요.
  파일 이름에 쓸 수 없는 글자(`/ : ? *` 등)는 자동으로 빠집니다.
- **🗑**로 지워요. 한 번 더 확인하고, **되돌릴 수 없어요.**
- **지금 열려 있는 채팅은 지울 수 없어요.** '열려 있음' 표시가 붙어 있어요. 다른 채팅으로 옮긴 뒤 지우세요.
- 캐릭터가 '마지막으로 연 채팅'으로 기억하던 채팅을 지우면, 실리태번처럼 그 캐릭터의 가장 최근 채팅으로 옮겨요.
- 그룹 채팅을 지우거나 이름을 바꾸면 그룹 정보(채팅 목록, 마지막 채팅)도 함께 맞춰요.

### 여러 개 한 번에 지우기

1. 검색칸 옆의 **☑**를 누르면 선택 모드가 됩니다.
2. 지울 채팅을 누르거나 **모두 선택**(지금 보이는 채팅 전체)을 고릅니다.
3. **삭제**를 누르고 확인합니다. 하나씩 지우고 결과를 알려 줘요.
4. **완료**를 누르면 선택 모드가 끝나요.

---

## 5. 설정

**확장 프로그램 → 채팅 로비**에서 바꿀 수 있어요.

| 설정 | 설명 |
|---|---|
| 시작 화면에서 최근 채팅 대신 전체 채팅 보기 | 끄면 실리태번 기본 '최근 채팅'이 다시 보여요. 마법봉 메뉴의 전체 채팅은 계속 쓸 수 있어요 |
| 한 번에 불러올 채팅 수 | 20 / 50 / 100 / 200 / 전체. 많을수록 오래 걸려요 |

---

## 6. 알아 두면 좋은 점

- 이 확장이 켜져 있으면 실리태번 '최근 채팅'의 **고정(핀)** 표시는 보이지 않아요(고정한 정보는 지워지지 않으니 설정을 끄면 다시 보여요).
- 채팅 폴더 바로 아래에 있는, 주인(캐릭터·그룹)이 없는 채팅 파일은 실리태번처럼 목록에서 빠져요.
- 채팅을 연 다음 처리는 실리태번 기본 방식을 그대로 따라요(페르소나 자동 선택, 첫 메시지 등).
  [Chat Setup](https://github.com/spaceship4415/st-chat-setup) 확장을 함께 쓰더라도, 이 목록에서 채팅을 누르면 입장창 없이 바로 들어갑니다.
