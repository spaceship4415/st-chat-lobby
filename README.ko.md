# 채팅 로비 사용 가이드

[English](README.md)

실리태번 시작 화면의 **'최근 채팅' 자리에 모든 캐릭터·그룹의 채팅 목록**을 보여 주는 확장입니다.
목록에서 바로 채팅에 들어가고, 이름을 바꾸거나 지울 수 있어요. 여러 개를 골라 한 번에 지울 수도 있습니다.
휴대폰에서 쓰기 편하게 만들었습니다.

---

## 1. 설치하기

1. 실리태번 위쪽의 **확장 프로그램**(퍼즐 모양 아이콘)을 누릅니다.
2. **Install Extension**을 누릅니다.
3. 이 저장소 주소를 붙여 넣고 **Install**을 누릅니다.

   ```text
   https://github.com/spaceship4415/st-chat-lobby
   ```

설치가 끝나면 시작 화면(채팅을 닫았을 때 나오는 화면)에 **전체 채팅** 목록이 보입니다.

---

## 2. 어디서 여나요?

- **시작 화면**: '최근 채팅' 대신 전체 채팅 목록이 보여요.
- **채팅 중에**: 입력창 왼쪽의 **마법봉 메뉴 → 전체 채팅**을 누르면 같은 목록이 창으로 열려요.

```text
전체 채팅
[🔍 이름·마지막 메시지 검색  ] [필터] [선택]
(필터를 바꿨으면) Sarah · 이름 순   ✕
⌄ 오늘 (8)
(사진) Seraphina ♥Alice        17:11  ⋮
       채팅 이름…              💬 52
       마지막 메시지 한 줄…
⌄ 어제 (3)
…
        [50개 더 불러오기]
```

---

## 3. 목록 쓰기

- **채팅을 누르면** 바로 그 채팅에 들어갑니다.
- 캐릭터 이름 옆의 **♥ 이름**은 그 채팅에 고정된 페르소나예요(누구로 대화했는지). 고정하지 않은 채팅은 표시가 없어요. 그룹 채팅은 캐릭터를 골라 볼 때 표시되지 않아요.
- **검색**: 캐릭터·그룹 이름, 채팅 이름, **마지막 메시지**에서 찾아요(대화 중간의 메시지는 찾지 않아요). 여러 낱말을 띄어 쓰면 모두 들어 있는 채팅만 보여요.
  검색 결과는 **어디에서 찾았는지**에 따라 '캐릭터·그룹 이름 / 채팅 이름 / 마지막 메시지'로 나눠 보이고, 찾은 글자가 표시돼요.
  (실리태번은 채팅 이름에 만들 때의 캐릭터 이름을 넣어서, 캐릭터 이름을 바꾸거나 카드를 복사해도 채팅 이름은 옛 이름 그대로예요. 그래서 옛 이름으로 찾으면 '채팅 이름'에 나와요.)
- **묶음 접기**: 날짜·캐릭터·찾은 곳 제목을 누르면 그 묶음이 접히고, 다시 누르면 펼쳐져요. 제목은 스크롤해도 위에 붙어 있어서 긴 묶음을 내려가다가도 바로 접을 수 있어요.
  접은 묶음의 채팅은 선택 모드의 **모두 선택**에 들어가지 않아요.
- **대화 내용까지 검색**: 검색하면 결과 맨 위에 카드가 생겨요. 누르면 모든 캐릭터·그룹의 채팅을 **대화 중간 메시지까지** 찾아서 **대화 내용** 묶음에 보여 주고, 찾은 메시지를 미리보기로 보여 줘요.
  채팅 파일을 끝까지 읽어서 오래 걸릴 수 있어요. 검색하는 동안 목록 맨 위 카드에 진행 막대와 '3개 찾음 · 캐릭터 4명 중 3명 확인'처럼 진행 상황이 보이고, **멈추기**로 언제든 멈출 수 있어요. 검색어를 바꾸면 결과는 사라지고 다시 누르면 돼요.
  여러 낱말이면 서로 다른 메시지에 흩어져 있어도 찾아요. 찾은 메시지 미리보기는 100개 채팅까지만 불러와요.
- **필터**: 검색칸 옆 **[필터]**를 누르면 캐릭터 고르기·정렬·새로 고침이 펼쳐져요(펼친 상태는 기억해요). 접어 둔 채로 캐릭터나 정렬을 바꿔 두었으면 검색칸 아래에 바꾼 것만 한 줄로 보이고 필터 버튼에 점이 찍혀요. **✕**로 바로 기본값으로 돌아가요.
- **캐릭터 고르기**: 채팅이 있는 캐릭터와 그룹(👥)만 **최근에 대화한 순**으로 나와요. 전체 채팅 수를 알면 이름 뒤에 채팅 수가 붙어요(예: Sarah · 7개). 같은 이름의 캐릭터가 여럿이면 카드 파일 이름이 대괄호로 붙어요(예: Seraphina [default_Seraphina_2]). 캐릭터나 그룹을 고르면 **그 캐릭터의 채팅만, 개수 제한 없이 전부** 보여 줘요. 이름 검색과 달리 옛 이름이 채팅 이름에 남은 다른 캐릭터의 채팅은 섞이지 않아요.
  고른 상태에서 검색하면 그 캐릭터 안에서만 찾고(대화 내용 검색도 그 캐릭터만 — 훨씬 빨라요), 없으면 [모든 캐릭터에서 찾기]로 바로 넓힐 수 있어요. 열 때마다 모든 캐릭터로 돌아가요.
- **정렬**: 최근 순 / 오래된 순 / 이름 순 / 메시지 많은 순 / 캐릭터별.
  최근 순·오래된 순은 **오늘, 어제, 이번 주, 이번 달, 2026년 9월 …** 제목으로 묶여요. 정렬은 마지막으로 고른 걸 기억해요.
- **새로 고침**(필터 안): 다른 곳에서 채팅을 만들거나 지웠을 때 목록을 다시 불러와요.
- 캐릭터를 골랐을 때와 '캐릭터별' 묶음 안에서는 캐릭터 이름·사진이 줄마다 반복되지 않게 **두 줄**로 보여요(첫 줄: 채팅 이름·날짜, 둘째 줄: ♥페르소나·메시지 수·미리보기).
- 미리보기에서는 `*`, `**`, HTML 태그 같은 꾸밈 기호를 빼고 글자만 보여 줘요.

### 불러오는 개수

채팅이 많으면 한꺼번에 불러오는 데 오래 걸려서, 둘러볼 때는 **최근 채팅부터 정해진 개수만** 보여 줘요(기본 50개).
나머지는 목록 맨 아래 **[50개 더 불러오기]**로 봐요.

- **검색할 때는 자동으로 모든 채팅에서 찾아요.** 처음 검색할 때 한 번만 '모든 채팅에서 찾는 중…'이 잠깐 보이고, 그다음부터는 바로 찾아요.
- 오래된 순·이름 순·메시지 많은 순으로 정렬해도 모든 채팅을 대상으로 해요. (최근 순·캐릭터별은 둘러보기라 정해진 개수만)
- 제목의 개수는 전체 개수를 알 때만 보여요.

## 4. 이름 바꾸기 · 삭제

- 각 줄 오른쪽의 **⋮**를 누르면 그 줄 아래에 채팅 정보(이름·메시지 수·용량)와 **[이름 바꾸기] [고정] [삭제]**가 펼쳐져요. 다시 누르면 접혀요.
- **고정**한 채팅은 둘러볼 때 맨 위 **📌 고정** 묶음에 모여요. 오래된 채팅이라 최근 목록에 없어도 고정 묶음에는 나와요. 검색 결과에서는 이름 앞에 📌만 붙어요.
  (늘 보이면 줄마다 자리를 차지하고 스크롤하다 잘못 누르기 쉬워서 안에 넣었어요)
- 이름은 같은 이름(대소문자만 다른 것 포함)이 있으면 바꾸지 않아요. 파일 이름에 쓸 수 없는 글자(`/ : ? *` 등)는 자동으로 빠집니다.
- 삭제는 한 번 더 확인하고, **되돌릴 수 없어요.**
- **지금 열려 있는 채팅은 지울 수 없어요.** '열려 있음' 표시가 붙어 있어요. 다른 채팅으로 옮긴 뒤 지우세요.
- 캐릭터가 '마지막으로 연 채팅'으로 기억하던 채팅을 지우면, 실리태번처럼 그 캐릭터의 가장 최근 채팅으로 옮겨요.
- 그룹 채팅을 지우거나 이름을 바꾸면 그룹 정보(채팅 목록, 마지막 채팅)도 함께 맞춰요.

### 여러 개 한 번에 지우기

1. 검색칸 옆의 **[선택]**을 누르면 선택 모드가 됩니다.
2. 지울 채팅을 누르거나 **모두 선택**(지금 보이는 채팅 전체)을 고릅니다.
3. **삭제**를 누르고 확인합니다. 하나씩 지우고 결과를 알려 줘요.
4. **완료**를 누르면 선택 모드가 끝나요.

---

## 5. 설정

**확장 프로그램 → 채팅 로비**에서 바꿀 수 있어요.

| 설정 | 설명 |
|---|---|
| 시작 화면에서 최근 채팅 대신 전체 채팅 보기 | 끄면 실리태번 기본 '최근 채팅'이 다시 보여요. 마법봉 메뉴의 전체 채팅은 계속 쓸 수 있어요 |
| 한 번에 불러올 채팅 수 | 20 / 50 / 100 / 200 / 전체. 많을수록 오래 걸려요 |

---

## 6. 알아 두면 좋은 점

- **고정(📌)은 실리태번 '최근 채팅'의 고정과 같은 목록**이에요. 실리태번에서 고정해 둔 채팅은 로비에서도 고정으로 보이고, 로비에서 고정한 채팅은 설정을 꺼서 실리태번 최근 채팅으로 돌아가도 고정돼 있어요.
  (단, 실리태번은 고정 목록을 시작할 때 한 번 읽어 두기 때문에, 로비에서 바꾼 고정이 실리태번 최근 채팅에 보이려면 새로 고침이 필요해요)
- 채팅 폴더 바로 아래에 있는, 주인(캐릭터·그룹)이 없는 채팅 파일은 실리태번처럼 목록에서 빠져요.
- 채팅을 연 다음 처리는 실리태번 기본 방식을 그대로 따라요(페르소나 자동 선택, 첫 메시지 등).
  [Chat Setup](https://github.com/spaceship4415/st-chat-setup) 확장을 함께 쓰더라도, 이 목록에서 채팅을 누르면 입장창 없이 바로 들어갑니다.
